# TEMMS next step

The current verification record, remaining limitations and next action live in
[docs/progress.md](docs/progress.md). Use that document for dated execution status;
a configured workflow is not evidence of a successful run.

Start with the [installation example](README.md#install-and-try), then try the
[real-model terminal demo](examples/live_swap/README.md). Contributors should read
[CONTRIBUTING.md](CONTRIBUTING.md), [AGENTS.md](AGENTS.md) and
[the architecture](docs/architecture.md).

TEMMS remains an alpha Python library with injected runtimes. General model quality,
performance benefits and customer deployment requirements need evidence from the
intended workload. The former platform prototype is retained in Git history.
